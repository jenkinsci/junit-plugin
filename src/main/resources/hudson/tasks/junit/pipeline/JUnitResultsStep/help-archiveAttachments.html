Archives the files that tests attach with TestReporter.publishFile (JUnit 5.12 or later) to Open Test Reporting reports, so they can be opened from the page of each test. They are archived like build artifacts, under test-attachments/, so they are stored by the configured artifact manager (for example in cloud storage) and removed together with the build.

Attached files are looked up relative to the directory of their report; files outside of it or outside of the workspace are ignored. Legacy JUnit XML reports are not affected.
